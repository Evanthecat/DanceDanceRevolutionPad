# DanceDanceRevolutionPad
This is a simple keypad that I made for Dance Dance Revolution similar games, like Friday Night Funkin' and the Lightner's Live minigame in Deltarune. It has a small 128x64 OLED display, 11 keys, and a knob for changing the keybinds.

# Case
The case consists of three parts: the base, the top plate (to hold the switches/PCB to the case), and the cover plate (to cover all the components and make it look nicer).

The parts should fit on top of each other and can be held together with four M3x5mx4mm heatset inserts and M3x16mm screws.
![alt text](Assets/Separated%20case.png)

# BOM
The materials needed for this HackPad are listed below:
- 11x Cherry MX Switches
- 11x White blank DSA keycaps
- 1x 0.91 Inch OLED display
- 1x Seeed XIAO RP2040
- 1x EC11E Rotary encoder
- 4x M3x16mm Screws
- 4x M3x5mx4mm Heatset inserts
- 1x Case (should be three 3D printed parts)
- 1x 3D printed knob
- 1x Custom PCB
